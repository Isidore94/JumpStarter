### 1. `audit_rule_evidence(repo)` — cited rules must have an INTERNALS heading (`tools/jumpstart.py`)

Today `cmd_check` at `tools/jumpstart.py:929-937` never reads `docs/INTERNALS.md`, and the
`rules carry evidence` block at `675-694` only tests that the file exists. Add one
function, `audit_rule_evidence(repo) -> list[Finding]`, and wire it in two places:

- `cmd_check`: `findings.extend(audit_rule_evidence(repo))` after line 936.
- `audit_structure`: when `docs/INTERNALS.md` is present, **replace** the OK "present"
  finding at 677 with the result of `audit_rule_evidence(repo)`, so `retrofit` keeps 25
  checks and the same check name. The MISSING branch (678-694) is untouched.

Behaviour of `audit_rule_evidence`:

1. Read `CLAUDE.md` at the repo root. Remove every `<!-- ... -->` block first (they may
   span lines). Then collect every citation written as `(INTERNALS: "<name>")`; the name
   may be wrapped across a line break, so join runs of whitespace (including newlines)
   inside the quotes to one space.
2. Read `docs/INTERNALS.md` and collect every `## ` heading (exactly two hashes then a
   space; `###` is not a rule heading). Strip one trailing parenthetical `(...)` and
   surrounding whitespace from each.
3. Compare case-insensitively after collapsing internal whitespace.
4. Results, check name `rules carry evidence` in every case:
   - No `CLAUDE.md` or no `docs/INTERNALS.md`: return **an empty list**. `retrofit`
     already reports a missing INTERNALS file; `check` must not fire on a repo that has
     no rulebook yet.
   - No citations: one `OK` finding, detail `no INTERNALS citations in CLAUDE.md`.
   - Every citation matched: one `OK` finding, detail `N cited rule(s), each with an entry
     in docs/INTERNALS.md`.
   - Any citation unmatched: one finding with status `MISSING` (`ok` false, so the exit
     code becomes 1), detail listing the unmatched names verbatim in citation order, e.g.
     `2 cited rule(s) with no docs/INTERNALS.md entry: "Some name", "Other name"`, and a
     remedy: `Add a '## <name> (<date>, <what prompted it>)' entry to docs/INTERNALS.md
     with the incident behind the rule, or fix the citation. Where the incident cannot be
     recovered, write 'Evidence not recovered' - never invent one.`

Report text stays ASCII (the `test_the_report_is_ascii...` test at 577 pins that). Do not
touch `audit_placeholders`, the size checks, the limit constants, or `templates/`. Whether
uncited rules (a bolded bullet with no citation) should also be flagged is out of scope — a
wider change is a separate packet (see "Still owed").

Binding invariants: standard library only; `retrofit` writes nothing; ASCII report;
`sha256(CLAUDE.md) == sha256(AGENTS.md)` after any doc edit (`jumpstart.py sync-agents .`).
